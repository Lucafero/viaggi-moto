# Viaggi in Moto

App per tappe e spese di gruppo durante i viaggi in moto. Funziona offline e si sincronizza con Firebase.

- Codice: `src/` (app.js, calc.js, db.js), file statici in `public/`
- Build: `npm install && node build.mjs`, poi copiare `dist/` in `docs/`
- Pubblicata con GitHub Pages dalla cartella `docs/`
